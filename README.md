# Moonwatch

A responsive, front-end meme coin radar for the Solana ecosystem. It includes token search, category filters, market snapshots, and a smart-money activity feed using demo data.

## Run locally

No build step is needed. Open `index.html` in a browser, or serve the folder with:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.
